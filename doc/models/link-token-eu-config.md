
# Link Token EU Config

Configuration parameters for EU flows

## Structure

`LinkTokenEUConfig`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `headless` | `boolean \| undefined` | Optional | If `true`, open Link without an initial UI. Defaults to `false`. |

## Example (as JSON)

```json
{
  "headless": false
}
```
